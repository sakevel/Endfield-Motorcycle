# 摩托车 / Endfield-Motorcycle

适用于《明日方舟：终末地》的载具模组，为游戏引入可自由召唤与骑乘的摩托车。自带定制的终末地工业白黄配色模型，配备完善的车辆动力学、转向姿态解算与惯性跳跃系统。

---

## 操作指南

| 按键 | 功能说明 |
|---|---|
| **长按 R 轮盘 → 摩托车** | 远处召唤到身边；在车旁再次选择则收回车辆 |
| **靠近车辆交互键** | 骑上摩托车 |
| **F7**（可在按键设置中修改） | 骑乘时下车 |
| **W / S** | 沿车头前进 / 倒车（倒车限速 3 m/s） |
| **A / D** | 左 / 右转动车把进行弧线转向 |
| **左 Ctrl** | 紧急刹车与减速 |
| **空格** | 车辆跳跃（保持骑乘状态） |

> **提示**：战斗、进入剧情过场、切换角色或使用技能时会自动安全下车并收回载具。

---

## 核心特性

- **拟真载具操控**：采用单轨载具运动学模型。前轮根据转向轴转动，车身自然向弯内侧倾压弯，前后轮根据实际转弯弧线行程差速旋转。高速行驶时具备转向自动收敛，操控平稳顺畅。
- **自适应坐姿 IK**：根据不同角色的身形骨骼比例求解坐姿。针对小体型角色自动适配前倾角度与抓握距离，手部精准扶把，双脚贴合踏板。
- **地形容错与车载跳跃**：内置手写车辆跳跃弹道与落差容错检测，支持连续地形起伏与离地腾空缓冲，空中姿态前仰后俯跟随真实行程。
- **动态视效与 FOV**：高速骑行时自动触发后轮拖尘与破风粒子特效；骑乘期间平滑扩展探索视野（FOV），带来更具速度感的驾驶体验。
- **自定义配置**：所有骑行物理参数均可通过游戏内模组菜单即时调整，修改即时生效。

---

## 配置选项说明

在游戏内按 `ESC` →「模组菜单」→「摩托车」→「模组配置」中可自定义各项参数：

- **基础设置**：最高速度、加速度、模型缩放比例、车头朝向、座垫高度。
- **操控调节**：最大转向角度、高速转向收敛幅度、制动响应。
- **跳跃与容错**：起跳速度、跳跃重力、速度跳跃增益、离地落差容错时间。
- **视效调节**：视野增量（FOV）、过渡时间、尾气/粒子特效起始速度与强度。

## 构建与安装

### 构建

```powershell
# 编译模组 DLL
.\tools\build.ps1

# 打包发行物
.\tools\package.ps1
```

构建产物位于 `build/package/Release/motorcycle`。

### 安装

退出游戏后，使用 ModLoader 的安装工具进行部署：

```powershell
..\Endfield-ModLoader\tools\install-mod.ps1 -ModPackage .\build\package\Release\motorcycle
```
