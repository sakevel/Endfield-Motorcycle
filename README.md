# 摩托车载具 (Motorcycle)

为《明日方舟：终末地》引入可自由召唤与骑乘的工业风摩托车载具，配备车辆动力学转向、自适应坐姿 IK 与车载跳跃控制。

## 操作方式

| 按键 | 功能说明 |
|---|---|
| **长按 R 轮盘 → 摩托车** | 召唤到身边；在车旁再次选择可收回车辆 |
| **靠近车辆交互键 (F)** | 骑上摩托车 |
| **F7**（可在按键设置中修改） | 下车 |
| **W / S** | 前进 / 倒车 |
| **A / D** | 转向 |
| **左 Ctrl** | 刹车制动 |
| **空格** | 车辆跳跃 |

> 进入战斗、剧情过场、切换角色或释放技能时会自动下车并收回载具。

## 功能特性

- **拟真载具动力学**：支持转弯倾斜压弯、差速轮转与高速转向阻尼收敛。
- **自适应坐姿 IK**：针对不同体型骨骼自动求解坐姿，小体型角色自适应抓握距离与脚踏位置。
- **地形起伏与跳跃**：支持连续地形缓冲起伏与带惯性的车载起跳。
- **动态视效与 FOV**：高速行驶触发尾部粒子破风特效与动态探索视野（FOV）拉远。
- **即时参数配置**：最高速度、加速度、转角、起跳高度等均可在游戏内「模组菜单」实时调整。
