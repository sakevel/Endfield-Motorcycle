# 骑乘姿态与多体型适配

本文档说明摩托车骑乘时的角色骨骼逆向动力学 (IK)、多体型适配算法、转向侧倾以及双轮贴地机制。

---

## 1. 姿态求解与体型适配

为了让不同体型的角色都能自然贴合车架结构，模组采用实时动态 IK 逆向解算驱动角色的四肢与躯干。

### 1.1 固定车身尺寸
- 车身比例由配置项 `scale`（默认 1.15）决定，自带模型基准长 2.2 米，渲染全长约 2.53 米。
- 无论何种体型的角色骑乘，车身均保持设定的几何比例，保证视觉上机械结构的体量感一致。

### 1.2 多体型与手臂适配
- **前倾躯干求解**：针对臂长较短的小体型角色，自动加大躯干前倾求解范围，使手掌能够准确贴合握把。
- **肩部与手腕朝向**：肩部带有反向微调以自然延伸手臂，手腕旋转对齐车把把手方向。
- **膝盖与腿部姿态**：膝盖 IK 极向目标（Pole）引导大腿贴近油箱两侧，脚掌精准踩在左右脚踏板上。

---

## 2. 转向侧倾与重心转移

在转向过程中，车体与角色躯干联动，模拟真实的摩托车压弯姿态。

### 2.1 车身侧倾 (Lean / Bank)
- 转向架根据转向角转动的同时，车身整体绕纵轴向弯道内侧发生侧倾。
- 侧倾角度与角速度使用临界阻尼弹簧进行插值平滑，回正过程平稳柔和，无机械式突变。

### 2.2 骑手重心移动
- **骨盆侧移**：高速或大角度过弯时，角色骨盆向弯道内侧平移（最大约 3.5 厘米）。
- **上身侧倾**：上身相对于车身进一步向弯内倾斜（最大约 5°）。
- **头部视向**：头部适度朝向弯道切线前方，形成自然的“视线注视出弯方向”的骑行神态。

## 3. 双轮贴地与悬挂解算

为确保车辆在不同地形（平地、坡道、台阶）上均表现真实，前后轮独立计算地面接触与车体俯仰。

### 3.1 地面采样与最低支撑点
- 每帧发射射线检测前后轮下方的可行走地面（Walkable Floor），取得路面高程与接触法向。
- 根据车轮局部几何与地面倾角计算轮胎最低接触点，保证轮胎切实着地。

### 3.2 坡度计算与俯仰控制
- **车身俯仰**：根据前后两轮的接触点高低差，计算车身纵向坡度俯仰角，自动贴合上坡与下坡地形。
- **悬挂模拟**：前后轮轴拥有可浮动的虚拟悬挂行程（最大 ±16 厘米），平滑吸收细微地形凹凸与起伏颠簸。
- **全生命周期贴地**：召唤停放、上下车以及行驶过程中均持续保持双轮贴地，避免浮空或车身严重穿地。
