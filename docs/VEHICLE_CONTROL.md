# 车辆操控与运动学模型

本文档说明摩托车单轨运动学模型、转向角解算、高速收角机制以及原生移动管线（NavMove）的集成方式。

---

## 1. 运动学模型与单轨几何

模组基于单轨机动车（Bicycle Model）运动学原理构建车辆操控体系，提供贴近现实摩托车骑行的动力学反馈。

### 1.1 独立航向与输入解析
- **输入来源**：读取原生 `PlayerController.rawMoveAxis` 输入量（X 轴为左右转向，Y 轴为前后加减速油门，带有 0.08 输入死区）。
- **独立车身航向**：车身独立维护 `bikeYaw` 旋转角，与角色的步行朝向及摄像机视角解耦。
- **真实车头转向**：静止状态下按下 A/D 键仅转动车把与前叉，车身不发生原地旋转。

### 1.2 转向轴与单轨几何
- **倾斜后倾角**：前叉围绕模型的真实倾斜转向轴（后倾约 31°）旋转，前轮轴的投影几何随之发生前移与侧偏。
- **单轨曲率推导**：
  设前轮转角为 $\delta$、轴距为 $L$、偏置为 $d$，后轮瞬时旋转曲率 $k$ 为：
  $$k = \frac{\sin\delta}{L \cos\delta + d \sin\delta}$$
- **Root 轨迹计算**：骑手根节点（Root）相对于后轮轴心具备纵向偏移 $a$ 与横向偏移 $b$，其综合运动轨迹切线与曲率由前后轮综合路径几何推导得出。

### 1.3 驱动与位移积分
- **导航派发**：在 `Tick` 阶段计算车体根节点的切线速度向量，发送至游戏原生的移动输入管线。
- **实际位移积分**：在 `TailTick` 阶段读取原生物理碰撞解算后产生的实际位移在运动切线上的投影 $ds$：
  $$\Delta \text{bikeYaw} = ds \cdot \frac{k}{f}$$
  以此方式驱动车身偏航角更新。遇墙体碰撞停滞或无实际位移时，车身航向保持不变，避免假位移累计。

## 2. 转向参数与高速收角机制

为了兼顾低速调头的灵活性与高速巡航时的行驶稳定性，模组引入了自适应转向角度约束。

### 2.1 最大转向角 (`max_steer`)
- **配置参数**：默认 35°（支持范围 10°–50°）。
- **几何含义**：定义前叉绕倾斜转向轴转动的机械极限偏角。数值越大，低速行驶和调头时的转弯半径越小。
- **可达性约束**：实际最大角度同时受角色手臂 IK 可达范围限制，确保过弯时双手紧握车把。

### 2.2 高速转向收角 (`speed_steer_reduction`)
- **配置参数**：默认 0.5（支持范围 0–1）。
- **收角机制**：随着车速增加，高速行驶下的横向加速度预算随之收紧：
  $$\text{speedLimit} = \min\left(\text{maxSteer},\ \arctan\left(\frac{\text{wheelbase} \times \text{lateralBudget}}{\max(v^2, 1)}\right)\right)$$
  实际允许的最大转角在 `maxSteer` 与 `speedLimit` 之间依据 `speed_steer_reduction` 强度进行线性插值。
- **效果**：在高速冲刺时自动平缓大角度转向，避免急转弯导致过大的视角甩动；低速和静止时保持完整的全向转向角。

## 3. 原生移动管线集成

### 3.1 导航接口调用
- 车辆运动完全通过游戏原生的 `MoveInput.NavMove` 接口驱动，保证角色能够正常响应游戏地图中的碰撞体、地形坡度与重力解算。
- 启动与退出时安全预检与恢复输入上下文，确保不残留全局输入劫持。

### 3.2 刹车与倒车
- **刹车制动**：按下左 Ctrl 键触发刹车，激活减速 handle，平稳制动至停止。
- **倒车控制**：按 S 键向后倒车时，最大倒车速度限制为 3 m/s，车轮反向旋转且转向几何对称生效。
