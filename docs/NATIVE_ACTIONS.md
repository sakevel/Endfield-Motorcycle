# 原生交互与召唤轮盘集成

本文档说明摩托车在游戏原生通用能力轮盘（GeneralAbility）、场景交互列表（InteractOption）中的集成机制与控制逻辑。

---

## 1. 原生能力轮盘集成 (R 键)

模组将摩托车的召唤与回收功能深度整合到游戏的原生通用能力轮盘中。

### 1.1 槽位注册与 UI 复用
- **轮盘入口**：长按 R 键呼出原生 `GeneralAbility` 轮盘界面（管理类为 `GeneralAbilityCtrl`）。
- **动态注册**：在轮盘的可用空槽位中注册类型为 `-73001` 的摩托车功能单元。
- **外观与交互**：复用原生 `GeneralAbilityCell` 控件、`uiStateCtrl` 状态机以及悬停动画，保持与游戏原生工具一致的操作体验。

### 1.2 触发逻辑
- **召唤**：场上无载具或载具距离玩家超过 3.5 米时，在玩家当前脚下可行走地面召唤摩托车，并播放 2 秒工业构建动效；
- **收回**：载具在玩家身边（距离不超过 3.5 米）且未骑乘时，再次在轮盘中触发即可回收摩托车，并播放工业拆除消融动效；
- **防重复保护**：动画播放期间锁定交互，防止并发生成多个载具实例。

---

## 2. 场景交互选项 (F 键)

当玩家步行靠近停放的摩托车时，游戏屏幕上将出现原生的场景交互选项。

### 2.1 交互条目生命周期
- **停放状态 (Parked)**：玩家靠近摩托车时，通过原生 `InteractOptionCtrl` 注册 `InteractOptionType.Interactive` 条目「骑乘摩托车」。
- **骑乘状态 (Mounted)**：进入骑乘后立即清除该交互条目，避免常驻遮挡画面。
- **主动列表更新**：注册条目后主动触发 `_TryUpdateShowingList` 与 `_UpdateBtnHint` 进行界面重算，确保玩家靠近时条目即时弹出。

### 2.2 上下车控制
- **上车**：在摩托车旁按下原生交互键（F 键）或手柄对应交互按键，平滑进入骑乘姿态。
- **下车**：骑乘过程中按下快捷键（默认 F7）或在遭遇强制下车事件（如受到攻击、进入过场）时平滑脱离载具。

## 3. 图标设计

- **模组徽章 (`assets/icon.png`)**：采用工业风格断开六边形框，搭配简洁的摩托车剪影与鲜黄色警示三角标志。
- **轮盘图标 (`assets/wheel-icon.svg`)**：定制的矢量双轮轮廓图标，针对游戏轮盘的分辨率进行像素对齐。
