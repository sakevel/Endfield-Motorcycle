# 整车碰撞与障碍检测

本文档说明摩托车在停放与骑乘不同阶段的物理碰撞体设计与障碍检测机制。

---

## 1. 碰撞体设计与层次划分

载具在停放与行驶两种状态下对物理碰撞的需求不同，模组对两者进行了分阶段处理：

### 1.1 停放碰撞盒 (Parked Collider)
- **碰撞盒尺寸**：在车体根节点下添加子对象 `ZML_Bike_Collision`，挂载 Unity `BoxCollider`（位于 `WALKABLE_LAYER` 层），盒体包围范围贴合车身实际几何。
- **初始防夹保护**：在召唤生成或玩家刚下车的瞬间，停放盒暂时保持禁用；待玩家角色走出车辆包围范围后自动启用。之后玩家再次靠近时将产生实体阻挡，防止穿模。

### 1.2 骑乘障碍扫掠 (Riding Obstacle Sweep)
- **动态盒体投射**：进入骑乘后停放盒自动禁用，改用基于运动学的 `Physics.BoxCastNonAlloc` 与 `OverlapBoxNonAlloc` 进行前进与后退方向的动态扫掠检测。
- **静态障碍判定**：查询 `ALL_STATIC_SCENE_WITH_TERRAIN_LAYER_MASK` 静态场景与地形层，自动排除载具自身与角色胶囊体。
- **碰撞响应**：在前进方向遇到不可穿过的静态建筑或墙体时，主动向移动输入层发送零速度限制，避免车头穿墙或强行挤入狭窄障碍。

---

## 2. 地面支撑与轮胎解算

整车的实际地面高度与轮胎支撑由专用的前后轮双点射线检测负责，独立于整车阻挡盒体，确保在楼梯台阶与倾斜地形上的顺畅通行。
