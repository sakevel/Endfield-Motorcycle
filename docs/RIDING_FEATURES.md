# 车辆弹道与物理特性

本文档说明载具跳跃弹道、轮胎粒子特效、动态视野以及状态判定的实现机制。

---

## 1. 载具弹道与跳跃物理

载具在骑乘状态下使用独立的弹道积分与运动管线（`flight.lua`），使车辆起跳与腾空行为具有连续的惯性与速度表现。

### 1.1 起跳动量与水平惯性
- **动量采样**：起跳瞬间继承地面行驶的实际水平位移速度窗口（约 0.1 秒滑动窗口），完整保留转弯切线与倒车动量。
- **状态接管**：地面检测到跳跃按键（Space）时，拦截默认的原生跳跃请求，将车辆切换至外部运动（External Flight）接管模式。
- **空中控制**：腾空期间不接受地面轮胎转向与刹车限速输入，轨迹完全由起跳动量与重力积分主导。

### 1.2 垂直速度与重力解算
- **初始向上速度**：由配置项 `jump_base_speed`（基础起跳速度）与 `jump_speed_boost`（速度加成系数）共同决定：
  $$\text{verticalSpeed} = \operatorname{clamp}(\text{jump\_base\_speed} + |\text{horizontalSpeed}| \times \text{jump\_speed\_boost},\ 2,\ 12)$$
- **重力积分**：空中每步物理模拟按 `jump_gravity`（默认 14 m/s²）进行加速度积分，计算下落速度与俯仰角度变化。
- **动态俯仰**：根据垂直运动轨迹自动平滑调整车身前倾/后仰姿态，上升时车头微抬，下落时车头微倾，落地时平滑回正。

### 1.3 碰撞扫掠与落地
- 每帧细分为小步长物理模拟，结合整车盒体扫掠与原生胶囊体移动（`TryMoveCapsule`）：
  - 遇到障碍物墙体时去除阻挡方向的水平动量；
  - 碰到天花板或上方障碍时向上速度归零；
  - 下降过程中接触可站立地面法向（Walkable Normal）时判定为着陆，平滑退出 External Flight 并恢复地面骑乘操控。

## 2. 轮胎粒子特效

载具在行驶过程中在前后轮胎位置生成动态扬尘与破风特效。

### 2.1 粒子系统挂载与定位
- **资源选用**：借用游戏原生粒子资源中的纯视觉叶子节点 `Smoke_Tuci_01`（扬尘）与 `feng1_di01`（破风线）。
- **发射锚点**：
  - **风线（Wind）**：跟随前后轮中心坐标，沿车体运动方向发射；
  - **扬尘（Dust）**：基于真实轮胎接触面，沿地面法向偏移发射，与实际路面贴合。

### 2.2 动态发射控制
- **速度阈值**：当车辆行驶速度超过 `speed_fx_threshold`（默认 5 m/s）时启动粒子发射，发射速率随速度提升按比例增强。
- **离地判定**：车辆腾空或处于静止状态时自动暂停扬尘发射；落地后重新激活。
- **资源生命周期**：下车或卸载模组时，立即停止发射并安全销毁自身克隆的粒子实例。

## 3. 动态骑乘视野 (FOV)

为增强骑行过程中的速度感与空间开阔感，模组提供了动态相机视野调整。

- **视野偏移**：当激活主关卡相机时，通过相机的 `runtimeFOVOffset` 属性动态叠加广角偏移（由 `ride_fov` 控制，默认 +12°）。
- **平滑过渡**：视野缩放采用指数平滑滤波，过渡时间由 `fov_blend`（默认 0.4 秒）控制。
- **恢复与清理**：下车、进入过场动画或切换至菜单时，视野自动平滑回退至原始参数。

---

## 4. 状态判定与下车规则

### 4.1 地形容错与跌落
- **离地容错时间 (`terrain_grace`)**：车辆离开地面时允许保持骑乘的最长时间（默认 3 秒），允许在小坡起伏或跳跃时保持乘骑。
- **最大下落高度 (`terrain_drop`)**：相对于最近地面高度的最大允许落差（默认 6 米），超出限制时自动触发下车并切入普通坠落状态。

### 4.2 强制下车事件
遇到以下游戏事件时，模组会立即注销骑乘状态并恢复角色默认控制：
- 角色进入战斗或遭受攻击击飞；
- 切换当前操控角色；
- 触发剧情过场、对话或打开全屏系统界面；
- 角色死亡或触发场景传送。
