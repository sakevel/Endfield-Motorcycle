# 测试与验证指南

本文档介绍 Endfield-Motorcycle（摩托车模组）的自动化测试套件与功能验证方法。

---

## 自动化测试

项目包含 Native C++ 合约测试与 Python / Lua 载具行为仿真测试：

```powershell
ctest --test-dir build -C Release --output-on-failure
```

### 测试套件说明

- **ContractTests (`tests/contract_tests.cpp`)**：
  - 验证模组导出函数 `ZML_PluginV1` 及 C ABI 结构完整性。
  - 校验内置模型分件数据（`.zmlmesh`）与贴图资源的哈希一致性与资产完整性。

- **BehaviorTests (`tests/behavior_tests.py`)**：
  - **载具状态机仿真 (`tests/scenarios.lua`)**：
    测试召唤、登车、行驶、倒车、刹车、下车与收回全生命周期的状态转移逻辑。
  - **按键绑定与输入解算 (`tests/keybind_scenarios.lua`)**：
    验证前进、转向、空格跳跃与下车按键的事件路由与死区过滤。
  - **碰撞与地形判定 (`tests/collision_scenarios.lua`)**：
    测试地面贴合计算、悬空计时与最大离地下落高度超时逻辑。
  - **跳跃物理弹道 (`tests/riding_features.lua`)**：
    验证车辆弹道垂直初速度积分、重力加速度与车身俯仰角平滑变换。

---

## 实机功能验证清单

在游戏内测试时，建议按以下流程逐项验证：

1. **载具召唤与收回**：
   - 处于开阔地形时，长按 `R` 打开轮盘选择摩托车，车辆应正常生成在角色身边并播放部署动效。
   - 靠近车辆时应显示原生交互提示，按下交互键后角色顺畅上车。
   - 角色上车后应呈现自然握把坐姿。

2. **驾驶操控**：
   - 按 `W` 正常加速前进，按 `S` 减速并可倒车（倒车限速 3 m/s）。
   - 行驶中按 `A` / `D`，车把与前轮应准确转向，车身向内侧倾。
   - 观察不同速度下的转弯半径与车把自动收敛表现。
   - 按住左 `Ctrl` 能快速减速刹车。

3. **跳跃与地形自适应**：
   - 行驶中按空格键起跳，观察车身离地腾空弧线与落地稳定性。
   - 行驶通过缓坡或台阶，观察离地容错时间内是否能持续保持骑乘。

4. **异常下车保护**：
   - 遭遇战斗、受到攻击、触发剧情对话或切换编队角色时，应立即自动解除骑乘并收回载具，角色控制正常恢复。
